# NovaPay Frontend (React App)

## 🚀 Overview
NovaPay frontend is a React-based web application that interacts with the backend microservices to provide a seamless digital payment experience.

---

## 🛠️ Tech Stack
- React (Vite)
- JavaScript (ES6+)
- Tailwind CSS
- REST API Integration
- Netlify (Deployment)

---

## ✨ Features
- User authentication
- Wallet management
- Transaction handling
- Rewards display
- Responsive UI

---

## 📦 Installation

1. Clone the repository
```bash
git clone https://github.com/RanjithRK14/novapay-react.git
```
2. Install dependencies
```bash
npm install
```
3. Run the app
```bash
npm run dev
```
---

##🌐 Deployment

The application is deployed on Netlify.

---

##🔗 Backend Integration

Make sure backend services are running before using the frontend.

Update API base URL in .env:

```bash
VITE_API_URL=http://localhost:8080
```
